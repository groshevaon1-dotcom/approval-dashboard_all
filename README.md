# Радар предоставлений — вся Россия (закрытый доступ)

Дашборд «Сообщение о предоставлении» (ст. 39.18 ЗК, без торгов) по всей России за 2024–2026.
Источник: открытые данные torgi.gov.ru. ~257 тыс. лотов. Фильтры: год + федеральный округ → регион (мультивыбор).

## Хостинг
Beget тянет этот репозиторий из git и отдаёт `index.html` **за паролем** (`.htaccess` Basic Auth).
Пароль задаётся файлом `.htpasswd` на сервере (в git не хранится).

## Обновление данных
Собирается пайплайном в `Торги/Радар торгов/_скрипты` (см. ЧИТАЙ_МЕНЯ_пайплайн.md).
Готовый `index.html` обновляется и пушится в этот репозиторий → Beget подтягивает.

> ⚠️ index.html тяжёлый (~84 МБ). Это MVP. Следующий шаг — PHP + MySQL: логин на клиента,
> срез данных по его регионам, лёгкая страница.
